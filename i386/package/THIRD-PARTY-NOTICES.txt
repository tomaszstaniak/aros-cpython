===================================================

Statically compiled INTO the interpreter binary (Python/python)
---------------------------------------------------------------
These are linked in; the guest does not need them installed separately. Full
license texts are in the licenses/ folder (one file per component).

  OpenSSL 4.0.1          Apache-2.0      _ssl, _hashlib
  jitterentropy 3.7.0    BSD-3-Clause    seeds OpenSSL's random generator
                         (or GPL-2.0)    (ABIv0 has no OS entropy source)
  xz / liblzma 5.8.3     0BSD            lzma
  Expat 2.8.2            MIT             pyexpat, xml.parsers (CPython's copy)
  mpdecimal              BSD-2-Clause    _decimal (CPython's copy)
  HACL*                  MIT             hashlib primitives (CPython Modules/_hacl)
  zlib 1.2.13            Zlib            zlib, gzip, zipfile deflate (the ABIv0
                                         SDK's static libz.a)
  bzip2 1.0.6            bzip2-1.0.6     bz2 (the ABIv0 SDK's static libbz2.a)

  (Checked against this binary with i386-aros-nm: it contains SSL_CTX_new,
   jent_entropy_init, lzma_lzma_encoder_init, mpd_qadd, inflate_fast,
   deflate_slow, BZ2_blockSort and BZ2_decompress as its own code. It has no
   SQLite: the i386 build has no sqlite3 module.)

Provided by the AROS SYSTEM at runtime (NOT in this archive)
------------------------------------------------------------
The interpreter opens these AROS shared libraries through the SDK's link
stubs; their code is not shipped here and their licensing is AROS's:

  sockets    -> bsdsocket.library  (AROSTCP)
  C runtime  -> the C library and the other system libraries

Unlike the x86_64 ABIv11 build, zlib and bzip2 are linked in (see above), so
z1.library and bz2.library are not needed.
